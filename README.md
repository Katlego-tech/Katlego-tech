### ⚡ Featured projects

- **[UbuntuRemit](https://github.com/Katlego-tech/UbuntuRemit)**: Cross-border remittance platform built around three agents: compliance, liquidity routing and settlement. Deterministic guardrails decide; the models only suggest. It builds ISO 20022 messages, routes payments through Ripple, SWIFT and PAPSS rail adapters, and writes to an append-only audit store. *(Python, FastAPI, Docker)*
- **[Tokelo](https://github.com/Katlego-tech/Tokelo)**: Serverless lease-compliance platform on AWS for South African tenants. Leases are uploaded to S3, read with OCR and checked against the Rental Housing Act. Lambda workers run behind EventBridge and SQS with dead-letter queues. Deployed to a staging environment. *(Python, AWS)*
- **[DropZone](https://github.com/Katlego-tech/DropZone)**: Time-limited access pass bought on-chain and enforced off-chain. The API issues a challenge, checks the wallet signature and only then grants a short-lived session token. *(Solidity, Foundry, FastAPI)*
- **[OmniCaption](https://github.com/Katlego-tech/OmniCaption)**: Dockerized video-captioning pipeline built with a teammate for the AMD Developer Hackathon: ACT II. It transcribes each clip, reads the visuals and writes four captions in different styles, all on AMD compute. *(Python, Docker, AMD ROCm)*
- **[Lekgotla](https://github.com/Katlego-tech/Lekgotla)**: Merges scattered AI-agent instruction files into one `AGENTS.md`, flags conflicting rules and hands each task only the context it needs. *(Python, FastAPI, Pytest)*
